# Figure Capabilities

All linked images are **SYNTHETIC DEMONSTRATIONS — NOT SCIENTIFIC PERFORMANCE EVIDENCE**.
Figure functions consume explicit analysis outputs, return `(Figure, Axes)`, do not save by default, and never train or refit models.

Typical use:

```python
from biomed_ml_workflows.figures.classification import plot_roc_curve
fig, ax = plot_roc_curve(labels, probabilities)
fig.savefig("roc.png")
```

## Scientific boundaries

The package validates obvious plotting shapes, not study validity. Cohort definitions, censoring assumptions, thresholds, calibration, external validation, and clinical interpretation remain outside the figure layer.
