# BioMed ML Workflows v0.1.0

## Scope

Reproducible biomedical machine-learning workflows and scientific visualization for Python 3.12.

## Supported workflows

- DenseNet121 2-D classification.
- SegResNet 3-D segmentation.
- CoxPH right-censored survival modeling.

## Figure capabilities

52 functions cover statistical, classification, segmentation, survival, and model-interpretation figures. Each accepts explicit inputs and returns Matplotlib objects.

## Validation

Public tests, the synthetic Quick Start, all figure demonstrations, package installation, headless exports, and release-cleanliness checks must pass for the tagged commit.

## Scope boundary

This software does not establish study validity, calibration, generalizability, clinical utility, or causal interpretation. Those require study-specific design and validation.
